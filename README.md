# MetaSim

LLM が考える住民が暮らす、渋谷の街の再現(シミュレーション)です。

## 何を作っているか

渋谷の駅のまわりを仮想の空間に作り、住む人・働く人・訪れる人を 1 人ずつ置いて、街の 1 日を 1 分刻みで走らせます。今の既定の世界に置く人は、合わせて約 35 万人です。

住民がどこへ行き、何を買い、誰と話すかを、住民 1 人ひとりの判断から決めることを目指しています。

## 目的

街に関わる意思決定のために、起こりうる未来を分布で示すことです。

未来は 1 つに決まりません。そこで、条件と偶然を変えて何本も走らせ、結果の広がりごと示します。何かを変えたとき(たとえば、催しを開く・決まりを変える)の効果は、同じ出発点から「変えた場合」と「変えない場合」を走らせ、その差で示します。

## 設計の柱

### 1. 住民の判断は LLM が行う

何に気づき、何をして、何を話すかを、行動の規則の表ではなく、住民ごとの判断で決める設計です。よく考える判断と言葉の中身は LLM が受け持ち、日常の軽い判断は、より小さな判断用のモデルに任せます。

### 2. エンジンは世界の決まりだけを受け持つ

設計では、エンジンが受け持つのは世界の決まり(物理と制度)だけです。住民の代わりに黙って決めることはせず、行動を止めるのは、物理と、現実でも物理的に止める仕組み(鍵や改札など)に限ります。世界の変化は、人の行動の結果として起こします(たとえば、棚の商品が増えるのは、店員が補充したから)。

### 3. 検証に使うデータは封印する

答え合わせに使う現実のデータは、最初に分けて封をします。作るときにも、調整するときにも見ない決まりです。予測を先に固定してから開けて比べ、作り手が結果を決めないようにします。

## 今の段階

設計と実装の段階です。実際の LLM を使った、小さな範囲の渋谷での検証は、これから行います。今の版が現実と合うことは、まだ示していません。

人の判断でまだ作れていない所は、仮の規則でつないでいます。つないでいる所は、仮のものだと宣言して記録しています。
